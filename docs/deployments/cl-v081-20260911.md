installed CL Codex terminal-quota detector byte-for-byte. The observed shared

credential home and ignores stale/user-authored errors. Its installed SHA256 is
`1e9edde515d8c5ca1cce0ce52705eecbf42cf353dc7b3a86d658f7643dfcc52b`.

role-skill delta is web-console's package manifest and lockfile. Rebuild those
dependencies using the service Node and verify the installed fallback behavior,
